# Joining the Sleep Leaderboard

You need a Garmin watch that tracks sleep and a Garmin Connect account. There
is nothing to install and no script to run. You just generate one key from
your own Garmin account and send it to the admin.

## Generate your Personal API key

1. On a computer, go to **https://connect.garmin.com/app/settings/personalApiToken** while logged in to Garmin Connect.
2. Select **Create Key**.
3. Read and accept the Terms and Conditions.
4. Choose an expiration period. **One year** is the easiest (least re-doing). Pick **90 days** if you would rather it expire sooner on its own. Garmin emails you about a week before it expires.
5. Select **Create**.
6. The key is shown **once**. Copy it and send it to the admin.
7. Select **Done**.

That is it. The key lets the leaderboard read your Garmin health data (sleep,
steps, activities). It does not contain your password or email.

## Good to know

- **If you lose the key** you cannot view it again. Just delete it on that same page and make a new one.
- **To leave the leaderboard** at any time, go back to that page and delete your key. The moment you delete it, the leaderboard can no longer read anything, no matter what the admin does.
- **Treat the key like a password** while you are copying it across. Send it to the admin privately, not in a public channel.
